# Privacy Policy for O-note

**Last updated: September 29, 2026**

O-note is a browser extension designed to help users create, store, and access personal notes associated with programming problems on supported websites such as LeetCode and Codeforces.

## Data Storage

O-note stores user-created notes locally in the browser using IndexedDB. O-note also uses Chrome's `chrome.storage.local` API to store user preferences and extension settings.

This data is stored locally on the user's device and is not transmitted to or stored on a developer-controlled server.

O-note does not use `chrome.storage.sync`.

## Data Collection

O-note does not collect personal information, analytics data, browsing history, or user-created notes for transmission to the developer.

O-note does not sell, rent, or share user data with third parties.

## Website Access

O-note accesses supported LeetCode and Codeforces pages to identify the current programming problem and display the appropriate notes panel.

The extension's website access is limited to the supported websites specified in its permissions.

## User-Created Content

Notes and other content entered by the user are stored locally by the extension. The user can manage this content through the extension, including creating, editing, deleting, importing, and exporting notes where those features are provided.

## Data Transmission

O-note does not transmit user notes, preferences, or other locally stored extension data to a developer-controlled server.

If the extension is modified in the future to introduce a feature that requires transmitting user data to an external service, this privacy policy will be updated accordingly.

## Changes to This Privacy Policy

This privacy policy may be updated if O-note's functionality or data practices change. The updated version will be published at the same location.
